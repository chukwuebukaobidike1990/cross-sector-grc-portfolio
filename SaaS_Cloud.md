# SaaS and Cloud GRC Playbook
**Risk landscape:** multi-tenancy, cloud configuration, identity, software supply chain, secure development, availability, data location and subprocessors.

**Priorities:** define shared responsibility; govern secure SDLC, secrets and dependencies; review infrastructure-as-code; test tenant isolation and recovery; manage subprocessors, transfers and deletion; provide accurate scoped assurance.

**Scenario:** cloud storage bucket becomes public. Restrict exposure, preserve logs, identify data and access window, assess notification duties and implement preventive configuration controls.
